# Pour-Over Dial-In

A repeatable framework for tuning a fresh bag on a flat-bottom dripper. The goal
is to change one variable at a time so the result is diagnosable, not a guess.

## Starting point

- Ratio: 1:16 (e.g. 18 g coffee to 288 g water).
- Grind: medium-fine, the same baseline every time so grind is the variable I
  move last.
- Water: just off the boil.
- Total brew time target: 2:45 to 3:15.

## The dial

1. Brew the baseline once and taste. Note whether it reads sour or bitter.
2. **Sour / thin / fast draw** → grind finer by a few clicks. Under-extracted.
3. **Bitter / dry / slow draw** → grind coarser. Over-extracted.
4. Re-brew, changing **only** the grind. Re-taste.
5. Once balanced, lock the grind and only then adjust ratio for strength.

## Notes

- One variable per brew or the result is noise.
- Fresh beans degas more; expect a faster draw in the first few days and adjust
  grind, not technique.
